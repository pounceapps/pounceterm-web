./run use-cases

Five workflows we actually run, played out in the simulator. Every scene autoplays as you reach it — replay any of them from the window controls.

Ship a fix while Claude runs the tests

Point Claude at a flaky test. It reads for free, edits in front of you, and the moment it wants to run anything, the Allow/Deny card is yours. Switch tabs while the suite runs — the finish notification finds you.

  • Reads free, runs gated — AI control
  • Background finish pings you — notifications

Two orgs, one email, zero relogging

Your account belongs to an Enterprise org and a personal plan. Make one profile for each, sign in once per profile, and run them in different tabs at the same time — the status bar always says which identity a tab is using.

  • Isolated logins per tab — Claude profiles
  • Works for any number of orgs, clients, or plans

Drive a remote box over Tailscale

SSH to the build machine (MagicDNS or 100.x address), start Claude there, and it still reaches PounceTERM's tools through the automatic reverse tunnel — while execution stays gated by that tab's AI-control.

  • Automatic reverse forward — the SSH tunnel
  • Tailscale-SSH check logins handled in-app — Tailscale

Babysit three agents in one group

Put api, frontend, and infra in a color group and tile it. Agents work in parallel; the one that needs a human raises a banner; Session Stats tells you who's been busiest and as which profile.

  • Groups, tiling, broadcast — tab groups
  • Per-tab measurement — Session Stats

Move files without leaving

Open SFTP on the same host — same SSH connection, no second login. Drag folders between panes, watch the queue, and Quick-Look anything from text to streamed video before you pull it down.

  • Dual-pane browser + viewer — SFTP
