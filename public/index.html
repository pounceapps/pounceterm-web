start claude --anywhere

Right-click any tab → Start Claude. Options for model, permissions, MCP connect — with a live preview of the exact command. On an SSH tab it runs on the remote host, and PounceTERM's tools reach back through an automatic reverse tunnel.

you hold the gate

Claude can read the screen and draft commands into your input line. Executing is different: it needs the per-tab AI-control toggle, off by default, that only a human can flip. Permission cards show up right where you're looking.

work + personal, side by side

Claude profiles are isolated logins — one email can hold a personal plan and Enterprise orgs, one profile per org. Different tabs run different identities at the same time, and the status bar always says which.
